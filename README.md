# lightcraft (Vibeclones mirror)

Hosted copies of the browser (WebAssembly) builds of [lightcraft](https://github.com/storytold/lightcraft), a Lightroom-style photo editor by ArtCraft. This repo only mirrors upstream release zips; the code is theirs.

- Latest: `/lightcraft/latest/`
- Specific version: `/lightcraft/v<version>/`
- Version list: `/lightcraft/versions.json`

Each version folder is the unmodified contents of upstream's `lightcraft-web-<version>.zip` release asset, including its license files. Upstream license: Apache-2.0. A scheduled workflow mirrors new releases.
